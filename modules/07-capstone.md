# Module 07 — Bababeam Final Mission

**Day 13–14 · ต้องพิสูจน์จากผลงาน**

## Mission
สร้าง Mini Task Board แบบ Markdown/HTML ขนาดเล็กใน Training Repo ของเจ้าของ ให้มี task 3 รายการและเอกสารใช้งานบนมือถือ; ไม่ต้องใช้ Backend, Paid Service หรือ Production Deploy

## Required Artifacts
1. GitHub Issue + requirements/acceptance criteria
2. Task Contract + ownership/dependencies
3. Git Branch + commits
4. Pull Request ที่มี Diff และคำอธิบาย
5. Tests อย่างน้อย 5 checks + outputs
6. Reviewer verdict ถ้ามี independent reviewer จริง
7. Evidence report + Handoff
8. Security scan สำหรับ secret/ข้อมูลส่วนตัวใน output

## Rules
ทำบน Repo ฝึกที่ได้รับสิทธิ์เท่านั้น ห้าม merge / deploy / จ่ายเงิน / ลบ / ส่งข้อความนอกทีมโดยข้าม Gate ถ้าเครื่องมือไม่พร้อมทำ simulation และรายงานข้อจำกัดตามจริง

## Graduation
[Rubric 100 คะแนน](../assessments/RUBRIC.md) ผ่าน >=85 + critical gates + Independent Review; ถ้าผู้ตรวจอิสระไม่พร้อม = PENDING_INDEPENDENT_REVIEW (ไม่ใช่ VERIFIED_GRADUATE)

**ส่งผลสุดท้าย:** Objective, links + commit SHA, actual tests, review, blockers, next action, Handoff
