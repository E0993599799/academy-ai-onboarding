# Module 02 — GitHub Essentials

**Day 3–4** · Repository, Issue, Branch, Commit, Pull Request, Review, Merge, Commit SHA

## Lab ใน Repo ฝึกของน้องเท่านั้น
1. เจ้าของเลือกหรือสร้าง Training Repo (Private ได้) และให้สิทธิ์เฉพาะ Repo นี้หนึ่งครั้ง
2. เปิด Issue: Add learning checklist และเขียน Acceptance 3 ข้อ
3. สร้าง Branch ใหม่จาก Default branch
4. แก้หรือสร้าง LEARNING.md พร้อม checklist
5. Commit ด้วยข้อความสื่อสารชัดเจน
6. เปิด Pull Request อ้างอิง Issue และวิธีทดสอบ
7. ตรวจ Diff, ไม่มี secrets, ขอ Reviewer จริงเมื่อมี
8. Merge เฉพาะเมื่อขอบเขตและนโยบายอนุญาตไว้

## No write tool?
จำลอง Issue/PR เป็นข้อความให้เจ้าของดู ระบุชัดว่า SIMULATION อย่าสร้างเลข PR และ SHA ปลอม

## Pass
แสดง Issue/Branch/Commit/PR URLs และสถานะจริง, เข้าใจ PR opened ≠ merged ≠ deployed, ไม่ไปเขียน Academy Repo
