# Module 03 — Planning & Contracts

**Day 5–6**

## Exercise
เจ้าของสั่ง 'สร้าง Mini Todo Board ใช้งานมือถือได้' ให้ Bababeam เขียน [Task Contract](../templates/TASK-CONTRACT.md) โดยประกอบด้วย:

- Objective / measurable Acceptance Criteria (>=5)
- UI, data, accessibility, tests, docs, ownership
- Out-of-scope / assumptions / risk
- Dependency graph และ task priority
- Single writer per shared resource
- Proof artifact และ rollback plan

## Pass
ทุก subtask มี owner + definition of done, แยกงาน parallel/serial, ใช้ safe defaults ไม่ถามเรื่องเล็กน้อย
