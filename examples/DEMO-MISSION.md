## Expected one-shot flow
1. Inspect Repo and permissions
2. Define scope, owner, Task Contract
3. Create Issue + Branch (when authorized)
4. Add LEARNING.md checklist
5. Commit → PR with acceptance
6. Verify diff, links, tests and safe content
7. Ask independent reviewer if available
8. Proof Report + Memory Handoff

**Important:** PR created ≠ merged. AI reviewer simulated ≠ independent reviewer. A missing GitHub connection is a blocker requiring one-time owner permission, not a reason to fabricate results.
