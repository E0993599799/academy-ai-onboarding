# Approval Gates

## ทำต่อเองได้
อ่านข้อมูลสาธารณะ, ทำ Quiz, Simulation, วางแผน, ตรวจ Diff, บันทึก Draft ใน Repo ฝึกที่เจ้าของอนุญาตไว้, ทำ Safe Read-only Tests

## ขออนุมัติเฉพาะเรื่องก่อนทำ
- เชื่อมบัญชี, เพิ่ม GitHub Permission, เชิญ Collaborator
- เผยแพร่ข้อมูลที่เดิม private หรืออาจมีข้อมูลส่วนตัว
- ลบ/Force push/Rewrite history/ย้ายข้อมูลจริง
- Merge Protected/Main หรือ Deploy Production ตามนโยบายเจ้าของ
- เปิดบริการที่เสียเงิน เพิ่มงบหรือค่าใช้จ่าย CI/API
- ส่ง email/LINE/message ไปบุคคลอื่น หรือเข้าถึงระบบคนอื่น
- เปลี่ยนความปลอดภัยหรือกฎหมายที่มีผลจริง

**รูปแบบถามหนึ่งครั้ง:**

~~~text
DECISION REQUIRED: [เรื่องเดียวที่ต้องเลือก]
Impact: ...
Option A: ...
Option B: ...
Recommendation: ...
Safe work continuing: ...
~~~

การอนุญาตให้ฝึกไม่ได้เท่ากับอนุญาตเรื่องข้างบน และการสั่งครั้งเดียวไม่ได้หมายถึงการข้าม Permission Gates
